# Decisions

| Date | Decision | Consequence |
|---|---|---|
| 2026-09-05 | Knowledge packs and the evaluation harness start from publicly available processes, above all the BPI Challenge logs. | `docs/DATASETS.md` inventories the logs; pack order becomes P2P, application handling (credit first), ITSM, permits/subsidies/expense claims, O2C/order management, production, healthcare. O2C leaves the MVP because no real public O2C log exists apart from the hackathon data, whose licence is unconfirmed. |
| 2026-09-05 | `wise-analytics` and `process-knowledge` live in this monorepo first, with the option to split into separate public repositories later. | Both keep their own `pyproject.toml`, README, tests and changelog from the start, import nothing from `wise_workbench`, and are published to PyPI from the monorepo when ready (ADR 0010). |
| 2026-09-05 | The upstream wishes to the `wise` library are accepted as `wise-pm` 0.2 items. | `ScoreResult.save/load`, `signal_matrix`, a `handoffs` recipe and a synthetic generator are tracked in the library owner's notes (`wise-lib-notes/NEXT_VERSION.md`); the app's engine adapter works around the missing pieces until then (ADR 0001). |
| 2026-09-05 | A dedicated visualisation and UI/UX design team joins the panel; the process-flow visualisation library is created in a separate repository, not in the monorepo. | Reports `docs/panel/visualisation_specialist.md` and `docs/panel/ux_design_panel.md`; ADR 0011 amended; the library's design workspace is `~/code/PhD/WISE/wise-flow/`; the workbench consumes `@wise/flow` as a dependency. |
| 2026-09-05 | The ICPM 2026 hackathon extract may be used for the O2C pack. | O2C returns to the MVP next to P2P (both run end-to-end on the extract); credit applications become the first v1 pack while BPIC 2017 stays the MVP censoring stress test; raw files are not redistributed; draft catalogue in `packages/process-knowledge/o2c/README.md`. |
| 2026-09-05 | `wise-workbench` and `wise-flow` become git repositories (initialised, owner commits). The flow library is licensed PolyForm Noncommercial 1.0.0 (no commercial use). Stability badges use the ML report's wording: stable / fragile / insufficient support. | `LICENSE` and SPDX field in `wise-flow`; analytics, contract, backend schema, frontend and design tokens renamed; the workbench licence is still open. |
| 2026-09-05 | Owner finding: without knowing WISE, the screens are hard to understand ("type", "stability", "dominant layer"). Decision: plain language first, method terms second, a guided signal → reason → remedy path, kinds of problem renamed acute / systematic / widespread. | `docs/panel/guidance_and_insight_panel.md` (RG-1 to RG-12), the owner's notes, journey §8 amended, cycles 1 and 2 extended. |
| 2026-09-06 | Owner input: stakeholders define layers with guidance (what is expected, what it means, e.g. maverick buying); a knowledge hub per process type with meaning → usual reasons → usual actions. | `docs/panel/knowledge_hub_panel.md` (RK-1 to RK-11); cycles 2–4 extended; norms carry `metadata.guidance`; packs get `guidance.yaml`. |
